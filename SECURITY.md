# Security policy

Report suspected vulnerabilities privately through GitHub Security Advisories. Do not open a public
issue containing credentials, personal documents, exploit payloads or account data.

Supported releases receive security fixes on the latest minor line. Rotate any exposed token before
reporting it. CareerTwin maintainers will acknowledge a report, assess severity and coordinate a
responsible fix and disclosure.

Never commit `.env`, database files, blob storage, exports, backups, access tokens or production logs.
