# ADR 0014: Versioned artifacts grounded in confirmed evidence

- Status: Accepted
- Date: 2026-08-01

## Decision

Résumé, cover-letter, interview-brief, and follow-up artifacts are new immutable versions identified by kind/title/version, linked to optional opportunity and exact confirmed evidence IDs. Deterministic composition is the safe baseline; model enhancement remains a draft.

## Consequences

Users can reconstruct what evidence supported a document and avoid silent replacement. Rich document export/templates can be added later without changing provenance. CareerTwin does not claim an artifact is truthful if the user edits it outside the evidence workflow.
