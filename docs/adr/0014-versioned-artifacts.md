# ADR 0014: Versioned artifacts grounded in confirmed evidence

- Status: Accepted
- Date: 2026-08-01

## Decision

STAR accomplishments and résumé, cover-letter, interview-brief, and follow-up artifacts are immutable versions identified by kind/title/version. They link to an optional opportunity and exact tenant-owned confirmed evidence IDs. A résumé variant contains only evidence explicitly selected for that version. Deterministic composition is the safe baseline; model enhancement remains a reviewable draft.

## Consequences

Users can reconstruct what evidence supported a document and avoid silent replacement. STAR structure makes interview evidence reusable without inventing outcomes. Rich document export/templates can be added without changing provenance. CareerTwin does not claim an artifact is truthful if the user edits it outside the evidence workflow.
