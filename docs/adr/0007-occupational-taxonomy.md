# ADR 0007: Pinned local ESCO with optional O*NET

- Status: Accepted
- Date: 2026-08-01

## Decision

Import a pinned ESCO release locally for multilingual skill/occupation URIs and search. Do not send profile text to public taxonomy services. O*NET is an optional future enrichment subject to its attribution/account/republication terms.

## Consequences

Normalization is reproducible and multilingual while concept URIs remain inspectable. Imports increase storage and require release provenance. Synonym/taxonomy mapping remains a suggestion until reviewed.
