# ADR 0018: Candidate-side assistance with explicit prohibited uses

- Status: Accepted
- Date: 2026-08-01

## Decision

CareerTwin serves the individual seeker. It does not rank candidates for employers, predict hiring, infer protected traits/personality/health, auto-apply, bulk-message, bypass access controls, or optimize deceptive keyword stuffing. Agents explain/draft/propose; users decide and act.

## Consequences

Product language, tests, UI, API, skills, and contribution review must uphold these boundaries. Features that move toward employer selection or autonomous applications require legal/ethical review and a superseding ADR, not a hidden configuration flag.
